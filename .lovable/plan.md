# إصلاح منظومة الأدوات والمهام في الشات

## الهدف
جعل تشغيل الأدوات واضحًا وموثوقًا داخل الشات، إصلاح بريد Megsy وتثبيته في القائمة، وإخفاء بيانات النموذج والتوكن.

## التنفيذ
1. توحيد حالة البث وحالة الأدوات لكل رسالة، وربط التحديث بالـ `clientId` بدل index متغير.
2. إبقاء مؤشر الأداة ظاهرًا أثناء التنفيذ، ومنع أزرار الإعجاب/النسخ/عدم الإعجاب حتى تنتهي الأداة.
3. إضافة أيقونات وتسميات واضحة للبريد وGitHub والكمبيوتر والبرمجة والنشر وباقي التكاملات، مع fallback نظيف.
4. إزالة معلومات النموذج والتوكن والتكلفة من واجهة الرسائل نهائيًا مع إبقاء metadata داخليًا للتشخيص.
5. جعل تثبيت Mail مرتبطًا بحساب المستخدم عبر إعداداته في Supabase مع تخزين محلي احتياطي ومزامنة فورية.
6. إصلاح تنفيذ أوامر Megsy Mail وإظهارها كأداة داخل الشات بدل تنفيذ صامت بعد الرد.
7. مراجعة توجيه مهام الصور والكمبيوتر والبرمجة والنشر والمهام الطويلة، وإصلاح العيوب الممكنة من هذا المستودع.

## التحقق
- اختبارات موجهة لحالة tool_call/tool_result ونهاية البث والأخطاء.
- اختبار تثبيت Mail بعد إعادة التحميل وتغيير الجلسة.
- اختبار Edge Functions الخاصة بالبريد المتاحة في المشروع.
- اختبار واجهة الشات بحساب مصادق عليه دون حفظ بيانات الدخول أو إظهارها.
- فحص البناء والسجلات بعد التعديلات، وتوثيق أي خدمة خارجية لا يمكن اختبارها بسبب غياب مصدرها أو مفاتيحها.

## تفاصيل تقنية
لن تُخزن أي بيانات دخول في الكود. المشروع متصل بالفعل بـ Supabase `Megsy`، وسيُستخدم الاتصال الحالي فقط. لن أدّعي نجاح خدمة خارجية إلا بعد استدعاء فعلي وقراءة النتيجة.
